Two Agents, One Bit

A federated pair recovers a causal graph neither can see in full. One bit of disclosure per round decides whether that is possible at all — and without it, the confounded case is not merely hard but formally unidentifiable.

The setup, in one paragraph

One structural causal model over five variables. Agent A sees its own private variable plus three shared ones; agent B sees its private variable plus the same three. Neither sees the other's private column. Edges between the two private variables are forbidden in both the generator and the prior, because no data either agent could ever collect would bear on them. Both act simultaneously, each with its own budget, and every intervention is hard.

Because B's private variable is hidden from A but still causally active, A's window is not a DAG — it is a latent projection in which two shared variables can appear correlated with no visible cause. We proved, and verified exhaustively, that this confounding can only ever touch shared pairs. That is what makes it tractable to model rather than merely lament.

The result that matters

GATE 3's lower arm is exactly zero, and the zero is mechanistic. A pair that never clamps cannot satisfy the success criterion on a confounded episode at any budget, ever — not because it is inefficient, but because without a clean batch of data the claim “these two variables share a hidden cause” is unfalsifiable. Any extra edge can be added and labelled confounding for the price of a complexity penalty. Clamping is what makes the claim testable.

That is a stronger statement than “clamping helps”, and it is the concrete argument for the regime bit.

Training

Independent PPO, one actor and one critic per agent. No centralised critic, no shared parameters, no shared observations. The only coupling is a shared scalar reward, which is necessary rather than incidental: a purely self-interested agent has no reason to clamp for its partner, so a per-agent reward would make the target behaviour strictly dominated.

The control: the same system without the bit

The no-bit arm is identical in every respect — same environment, same belief rule, same budget, same seeds, same number of training episodes. One flag differs: whether an agent is told that its partner clamped something it cannot see.

Read this carefully

Without the bit, independent PPO collapsed to passing in every one of 20 seeds: mean steps 0.0, final policy entropy near zero, a fully deterministic do-nothing policy. With the bit, no seed collapsed.

But the baselines still score ~0.53 in the no-bit arm, which means the no-bit task is solvable by acting randomly. So this is a LEARNING failure, not an impossibility proof, and the honest claim is narrower than the numbers first suggest: the bit is what makes the problem learnable by this method, not what makes it solvable in principle.

Blocking the pass action for the first 40 updates did not rescue it — the policy collapsed again once the block lifted. So “passing is too tempting early” is ruled out as the explanation.

Against the baselines

Every comparison holds the belief rule fixed. Cross-rule numbers are void — a policy trained under one scoring rule and evaluated under another collapses below random, so performance belongs to the (policy, rule) pair rather than to the policy.

Decisions and corrections

Recorded because the corrections were more informative than the successes, and because each one was found by a measurement rather than by inspection.

What changedWhy
Belief moved from enumeration to a subset DP 543 graphs per window died at k=6. The DP is exact, matches the frozen enumeration to 1e-10, and reaches k=10 — 4.2×1018 graphs, where enumeration is not slow but impossible.
Confounding orientation is marginalised, not tie-broken The old rule oriented each confounding edge “along the DAG's topological order”, but a DAG has many such orders and the code picked one by node numbering. Two shared nodes that are incomparable had their hypothesis decided by an implementation detail, worth up to 130 nats.
Identification requires the confounding claim too Three criteria were tried. Requiring the exact graph gave the confounded agent exactly zero at every budget. Marginalising the confounding away leaked, because the label is unfalsifiable without clean data. The criterion asks for both.
GATE 1 runs under a DAG-only rule Its target is the fraction of windows alone in their equivalence class, a quantity derived under a DAG model. Measuring it under the confounding-aware rule tests the rule rather than the environment.
Each agent gets an independent random stream Both were built from the same seed, so the two random agents chose the same shared target on 78% of rounds against the 19% expected of independent agents. The primary floor was a synchronised pair, which wastes one move per round and is easy to beat for the wrong reason.
Budget set to 8–10 for training The gates want opposite budgets: discrimination peaks at 2–3 and is gone by 16, while coordination registers nothing below 5, because an agent must spend moves clamping for its partner and moves experimenting on itself.

What this does not establish

Stated plainly, because a result is only as good as the list of things it is not.

  • GATE 2 is unresolved. The myopic oracle scored below random on unconfounded episodes. Two explanations were tested and falsified — it generates more clean data than random, not less — and the live hypothesis is that two greedy agents computing the same objective over overlapping authority collide. Until that is settled, the greedy arm is not a trustworthy reference.
  • One topology. Everything here is (1,1,3). The binding constraint on growth is the shared set, not the window: the confounding hypothesis space is exponential in the number of shared pairs.
  • The no-bit arm is the control and is still running. Until it lands, the value of the regime bit is argued from the gate, not measured end-to-end against a trained counterpart.
  • Whether the disclosure is admissible is not a technical question. The bit reveals that a hidden variable was fixed, never which one or to what value, and needs no central server. Whether that is within the federation constraint is the supervisor's call.
