Federated active causal discovery — the setup

3 agents · 3 private variables each · 3 shared · d=12 · window k=6 · scale-free (m=2) · seed 3

1. The system — the true DAG over every variable

Each agent's private block has its own colour; the shared block is grey. No edge ever runs between two different private blocks — that is the jointly-visible mask, and at this topology it forbids about half of all ordered pairs.
