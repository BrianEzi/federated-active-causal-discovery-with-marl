# 🧠 MARL Agent Architectures & IPPO Control Layer

This document details the Multi-Agent Reinforcement Learning (MARL) control layer implemented in `src/marl/`, built using DeepMind's **Haiku** and **Optax** following the Independent Proximal Policy Optimization (IPPO) paradigm.

---

## 1. Decentralized IPPO Architecture (`src/marl/ppo_agent.py`)

> **⚠️ Architectural note (see `docs/CHANGELOG.md`, "Collapsed ActionCategory to INTERVENE/NOOP"):** the Graph Head described in Section A.3 below was removed from the actor networks. `IPPOActor`/`InductiveIPPOActor` now only return `(cat_logits, target_logits)` -- the action head is a single-stage `[INTERVENE, NOOP]` category plus target, not the dual-head architecture described here. Predicted DAG structure comes entirely from the fixed analytic invariance scorer in `FederatedCausalEnv`, not a learned network. Sections A.1/A.2 (node embeddings, action head) still broadly apply, modulo the category count.

Unlike value-based methods (like QMIX) which rely on a centralized mixing network, IPPO trains a completely decentralized Actor and Critic for each agent. This ensures strict privacy boundaries, as agents learn entirely from their local observation states.

### A. Dual-Head `IPPOActor`
The Actor network is responsible for both executing interventions (actions) and predicting the structure of the local causal graph. It features a novel **Dual-Head Architecture**:

1. **Node Embeddings**:
   The input observation (flattened running covariance matrix) is unflattened and projected into a dense $N_e$-dimensional space. Each variable $X_i$ receives its own dense node embedding vector $e_i$.

2. **Action Head (Hierarchical Multi-Discrete)**:
   - **Stage 1 (Category)**: Outputs logits for three high-level intervention categories: `[Local Intervention, Peer Request, NO-OP]`.
   - **Stage 2 (Target)**: Outputs target logits for specific nodes in the graph. The target logits are generated by passing the node embeddings through a shared MLP, ensuring the action space can scale dynamically with the graph size.
   - **Target Masking**: Crucially, targets are dynamically masked with $-10^8$ based on the agent's jurisdiction. Agents cannot target nodes they are not permitted to observe or intervene upon.

3. **Graph Head (Shared Edge Scorer)**:
   The Actor continuously outputs a dense predicted local DAG matrix $\hat{A}_{k}$. It computes edge probabilities $P(X_i \to X_j)$ by concatenating the source and target node embeddings $[e_i, e_j]$ and passing them through a shared Edge Scorer MLP. This matrix is returned at every environment step.

### B. `IPPOCritic`
The Critic is a standard Feedforward MLP that evaluates the value $V(o_k)$ of the agent's current local state. Crucially, it only sees the local observation $o_k$, maintaining strict decentralization during both training and execution.

## 2. Training Protocol (`src/marl/ppo_trainer.py`)

The training loop (`IPPOTrainer`) utilizes a standard on-policy actor-critic update:

- **Rollout Buffer**: Trajectories (observations, actions, log-probabilities, rewards, values) are collected in a batched `RolloutBuffer` across multiple environment episodes.
- **Generalized Advantage Estimation (GAE)**: Advantages $A_t$ are computed using GAE ($\lambda=0.95$). To prevent catastrophic forgetting and gradient explosions when encountering sparse, massive reward shifts, **GAE advantages are batch-normalized** ($\mu=0, \sigma=1$) before the PPO update.
- **PPO Clipped Surrogate Loss**: The policy network is updated using the standard clipped PPO objective to prevent destructively large policy updates.
- **Global Gradient Clipping**: Both Actor and Critic optimizers are wrapped in `optax.clip_by_global_norm(0.5)` to provide an absolute ceiling on gradient magnitude, ensuring policy stability.
- **Entropy Bonus**: An entropy regularization term is added to the Actor loss to encourage exploration over the hierarchical action space.
- **Graph BCE Loss & Logical Hard Masking**: The Graph Head is trained using Binary Cross-Entropy (BCE) loss in a supervised manner against the true graph $G^*$. Crucially, the graph logits are multiplied by a **Logical Hard Mask**. This mask is constructed via the logical `OR` of the agent's Domain space and Boundary space. This physically isolates the domains, preventing the agent from ever predicting an invalid cross-domain edge (e.g. A1 Private to A2 Boundary), while successfully permitting boundary stitching.
