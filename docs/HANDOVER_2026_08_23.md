## 2. The project, in one page

MSc thesis: **federated active causal discovery with multi-agent reinforcement learning.**

Several agents each observe part of one causal system. Each has **private** variables nobody
else sees and **shared** (exposed) variables everyone sees. Each round an agent spends budget
to **intervene** (clamp) a variable it has authority over; everyone observes the resulting
samples on variables they can see; each agent updates its belief about the structure of its
own window. The research question:

> Can agents learn to *choose experiments* better than a myopic greedy baseline, and does
> cooperative, privacy-preserving information sharing help?

The **active** part is the contribution. No published federated causal discovery does
experiment selection — see `docs/BIBLIOGRAPHY.md` §17, where the four closest papers are
positioned.

**Hard constraints from the supervisor:** no central server; no information about private
variables crosses the boundary (one exception approved 2026-08-23, see
`docs/DISCLOSURE_DESIGN.md`).

**Deadlines: experiment freeze 31 August 2026. Dissertation due 8 September 2026.**

## 3. Why we are replacing the Bayesian engine

The belief was exact Bayesian: BGe marginal likelihood over linear-Gaussian SCMs, summed over
all DAGs by a subset dynamic program. Three measured limits (`results/cb_feasibility.json`,
`results/disclosure_scaling.json`):

**Confounding layer explodes.** The layer enumerates DAGs over the shared set:

    |X|=3 -> 25 assignments, 0.028 s      |X|=5 -> 29,281, 60.1 s
    |X|=4 -> 543, 0.577 s                 |X|=6 -> 3.78M, dead

**The window caps near k=12.** Exact DAG posterior alone, no confounding layer: k=9 is
0.102 s, k=12 is 2.95 s, **k=15 is 105.9 s**. The docstring claiming "carries to k~15-20" is
optimistic by a wide margin.

**BGe is linear-Gaussian only.** No nonlinearity, no discrete or mixed variables.

Constraint-based at d=30 is 0.47 s for a single skeleton search, 24 s with 50 bootstrap
replicates (serial; it parallelises). **But at our current small scale it is ~6x SLOWER** —
crossover is near k=6-7. We pay now for scale later.

**The strongest argument is not speed.** `ma/env.py` used to refuse any topology hiding more
than one node from an agent, because `clean` is a scalar fraction `n_clamped/len(hidden)` and
the mixture knows how many hidden nodes were clamped, never which. That guard was removed on
2026-08-23 (see §6). A constraint-based engine has no clean/dirty mixture, so the defect does
not exist — **which is what makes rung 1, three agents, runnable at all.**

## 5. What `cb/` does, and its one known bug

### The pipeline

1. `citest.FisherZ` — partial correlation on the usable rows. A row is dropped for a test
   when **either** variable was clamped in it.
2. `skeleton.estimate_skeleton` — start fully connected; for each pair look for a
   conditioning set that separates them; record the **separating set** of every removed edge.
3. `orient.orient` — place PAG endpoint marks. Each edge END is `CIRCLE` (undetermined),
   `ARROW` (not an ancestor) or `TAIL` (is an ancestor). Sources, in order: interventional
   ancestry, colliders, Meek R1/R2, then interventional confounding.
4. `bootstrap.bootstrap_belief` — B replicates, count edge states, return `[k,k]` frequencies
   **shaped exactly like `WindowBeliefDP.edge_marginals`** so the swap is invisible downstream.

Confounding is read off the graph — arrowheads at both ends — with **no enumeration**. That
is what removes the `|X|=5` wall.

### Three bugs already found and fixed. Do not reintroduce them.

Recorded because all three passed the entire existing test suite, and none would have been
distinguishable from "the agent has not learned yet" if checked through a metric.

1. **Unoriented read as confounded.** The first version tracked directions only and marked
   every edge it could not orient as bidirected — a plain chain reported confounding
   everywhere. Markov equivalence leaves edges unoriented for want of *information*, which is
   not evidence that neither node causes the other. Hence endpoint marks.
2. **Vacuous ancestry.** The second inferred an arrowhead wherever the opposite end had one
   and no *directed* path made the near end an ancestor — a textbook collider `0->2<-1` came
   back as two confounded pairs, because at that point nothing is directed so "not an
   ancestor" is vacuously true.
3. **The mean test was blind to our own experiment.** `ancestral_evidence` used a t-test on
   means. A clamp sets a node to 0.0 and observationally `E[x]` is already 0, so a child sees
   **no mean shift at all** — only a variance drop. It detected nothing on precisely the
   intervention our agents perform. Now tests mean (Welch) **and** variance (Levene).

### THE OPEN BUG — fix this first

**Power is checked per NODE, not per PAIR.** `orient` step 4 calls a pair confounded when it
is adjacent and neither clamp moved the other. To stop a *missed detection* becoming a false
confounder, `require_power=True` demands each clamp moved *something*. That check is global.

Consequence, pinned as an **xfail** in
`tests/cb/test_orientation_ground_truth.py::test_chain_and_branch_reports_no_confounding`:
on `0->1->2` with `0->3`, clamping 0 is detected on 1 (so the global check passes) but the
effect on 3 falls under the variance threshold, so `(0,3)` is reported confounded. **False
positive on a graph with no latent anywhere.**

`require_power=False` finds true latents that `True` misses (when the pair has no observed
descendant) but reintroduces the false positives. **Both settings are wrong in one
direction.** `True` is the better default — `test_a_true_latent_is_detected_when_the_pair_has_
an_observed_descendant` shows detection works on a realistic 4-node window at **P=1.00** on
the directed edges — but it is a default, not a fix.

**The fix is a per-pair power calculation:** for the specific pair `(u,v)`, was the clamp on
`u` powerful enough to have detected an effect on `v` of plausible size, had one existed?
Until that exists the engine over-reports confounding, which is the failure mode this project
can least afford — the whole thesis is about confounding.

## 6. Traps that have already cost time

**`ma/env.py`'s multi-hidden-node guard was REMOVED on 2026-08-23** by the student's
instruction, with a long note in its place. The exact Bayesian path is **unsound** for
`widest_hidden > 1` — it scores the wrong hypothesis, it is not merely approximate. Do not run
the exact backend on such a topology and trust the numbers. The original guard is at
`git show main:ma/env.py`. Three tests were converted rather than deleted; the defect is now
*demonstrated* by `tests/test_env_turns.py::test_clean_fraction_cannot_say_WHICH_node_was_clamped`.
If someone makes `clean` per-node, that test should start failing and be flipped.

**`crosscheck/legacy/ma_v1` is a reference oracle, not dead code.**
`tests/crosscheck/test_belief_dp.py` imports `AgentView` for `view.dags`, which fixes the DAG
ordering the frozen fixture `tests/fixtures/ma_reference_posteriors.npz` was built against.
Substituting our own enumerator risks a silent ordering mismatch. `legacy/` was deleted
wholesale during cleanup before this was noticed; only `ma_v1` was restored.

**`ma/projection.py` holds two DIFFERENT confounding criteria and they must stay separate.**
`bidirected_pairs` is the MAG definition and is authoritative — `env._confounded_positions`
and the 2.3% structural-ceiling figure both use it. `common_source_pairs` over-reports: where
a real `u->v` coexists with a hidden common cause, `u` **is** an ancestor of `v`, so the MAG
carries `u->v`. `test_the_two_confounding_criteria_diverge_and_the_difference_is_recorded`
pins this with a worked case.

**`ma/nets.py` was moved verbatim and must stay verbatim.** `tests/test_depth.py` requires
`layers=1` reproduce the d=4/5/6 networks *exactly* — same parameters, same RNG draw order.
Tidying it silently invalidates those results.

**Do not run the full suite alongside a CPU-bound job.** Done once; the suite took 2:25
instead of 3:40 and starved the other job for hours.

## 7. Standing practices — these are the student's rules, not suggestions

- **Spec before coding.** Agree the design with the student before implementing. Four bugs in
  one day were all silent design decisions made mid-implementation.
- **Verify DIRECTLY, not through a consumer.** A broken sampler looked like a mixing problem
  for three rounds because it was measured through the oracle. The three `cb/` bugs above were
  all caught by checking the engine's own output against hand-written graphs.
- **Verify on REPRESENTATIVE data.** A subset DP passed 29 tests on `rng.normal` then returned
  zero on the first real episode.
- **Test that metrics can be EARNED, per regime.** A metric that was structurally unearnable
  passed 529 tests.
- **Log incrementally** — `[MEASURED]` / `[DECIDED]` / `[CORRECTED]` entries into
  `docs/logs/SA_EXPERIMENT_LOG.md` as they happen. Keep nulls and self-corrections.

  wrong argument. `docs/BIBLIOGRAPHY.md` uses VERIFIED / STANDARD / UNVERIFIED.
- **Terse, direct writing.** No buzzwords.

### Next actions, in order

1. **Fix the per-pair power bug** (§5). Everything downstream is untrustworthy until this is
   done — the engine currently over-reports confounding, and confounding is the thesis.
2. **Phase 1, the boundary.** `belief_backend: "exact" | "constraint"` and
   `policy_arch: "gnn" | "mlp"` on `MAConfig`; one branch in `ma/env.py:_refresh()`. Write
   `cb/backend.py` to satisfy the same protocol as `crosscheck/belief_dp.py`. Half a day, and
   it makes the arm grid free.
3. **Identification criterion for the constraint backend.** Reward currently fires on
   `posterior mass on the true DAG >= threshold`; there is no posterior mass any more. The
   analogue is *fraction of bootstrap replicates recovering the true structure*. Needs the
   metric-reachability test.
4. **Phase 3, the GNN.** `PerNodeActorCritic` is already in `ma/nets.py`. It needs a wrapper
   adding **role features** (`is_shared`, `has_authority`) — without them the net cannot
   express "clamp my own private node", which is the headline behaviour. Equivariance then
   holds *within* roles, not across. Also route the extra observation (budget and signals
   global, disclosed per-node) and mask non-authority actions.
   **The student wants results from the GNN. The MLP is only the attribution arm.**
5. **Phase 4, cross-check.** Both engines on identical seeded episodes at `k=4-5` where both
   run, asserting agreement on the **verdict**, not equality of marginals. They are different
   estimators. This is the most likely place a silent bug surfaces.
6. **Phase 5, scale.** Grow private sets, exposed fixed at 3:

   | topology | private each | d | k |
   |---|---|---|---|
   | current | 1 | 5 | 4 |
   | scale-1 | 4 | 11 | **7** |
   | scale-2 | 5 | 13 | **8** |
   | scale-3 | 6 | 15 | **9** |

   At `k=7` each agent has 4 nodes hidden from it — exactly what the removed guard forbade —
   so **the scale ladder only runs on the constraint engine**. `k=4` is where both run and we
   cross-check. More agents comes after, not before.

   **Measure one episode's wall-clock at k=9 and set `B` from it before committing to a grid.**
   At `B=50` an episode is ~47 s, so 500 episodes is 6.5 h per seed. `B=20` gets it to ~2.8 h.
