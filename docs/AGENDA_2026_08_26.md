## Tier 0 — cheap measurements, run first

1. **Foreign rows in the skeleton's CI tests.** `foreign` gates `ancestral_evidence` and
   `pair_power` but NOT `_rows_for`, so rows where an unseen node was manipulated are pooled
   into the independence tests that build the skeleton. Re-run the error census with them
   excluded and compare missed-edge counts. *Student's instruction: do not spend long on
   this.* Timebox it; if inconclusive, record and move on.
2. **Behavioural transfer metric** — duplicate-coverage rate (how often two agents intervene
   on the same shared node). Separates "the policy stopped coordinating" from "coordination
   stopped paying". Currently the transfer failure has two explanations and we cannot tell
   them apart. **Highest value per hour on this list.**
3. **Scale the learned result in the deterministic environment** — 8 and 20 agents, **and
   private-set size ≥ 2** (student's amendment). ~25 min per 20k-episode run. Extends the
   headline claim from 4 agents / 7 nodes to the range the scaling analysis already covers.
4. **Clique-signature check** — does the engine recover the bidirected clique induced by a
   known hidden common cause? A single latent parent of {u,v,w} makes every pair among them
   bidirected, so the clique IS the signature. Doubles as a diagnostic on the 38% of
   confident errors that are confounding misreads. *Keep it cheap.*

## Tier 1 — small changes, large effect on how results read

5. **Rounds-to-identification as the primary metric**, with optimal-rounds as baseline
   (computable exactly in the deterministic env by the same search as the ceiling).
   Continuous instead of binary ⇒ much tighter intervals from the same episodes, and a true
   zero. **Requires no retraining** — re-score the existing five policies.
6. **Require every type claim** (`cb/claims.py`, one line). Removes the exemption of
   shared-block directions, which was justified by a false claim (see CORRECTION below).
   Makes identification mean "recovered the window", and enlarges what coordination can win.
7. **Cumulative partner-intervention counts** in the observation: per (other agent × shared
   node), budget-normalised, alongside the existing own-counts. The policy is FEEDFORWARD,
   so per-round disclosure it cannot retain is information the environment reveals and the
   agent structurally loses. Same class of fix as own-counts, which was the last unlock.
   Discloses nothing new — these are shared nodes, already disclosed in the round they
   happened; it converts disclosure into memory.

Items 6 and 7 change `obs_size`; land them together, then retrain the deterministic arms
once.

## Tier 2 — promoted by the student to high priority

8. **`cb_skeleton_alpha = 0.05` as default**, after one paired run. *What it does:* the
   engine currently uses ONE significance threshold (0.01) for both the skeleton's
   independence tests and the interventional orientation channels, whose error costs are
   opposite — a missed edge is an outright wrong adjacency claim, while a spurious
   orientation signal corrupts the type claims. Loosening the shared knob recovers edges but
   doubles type errors (measured: 16 → 32 at alpha 0.10). Splitting them and loosening ONLY
   the skeleton gives: missed edges 15 → 9, invented edges unchanged at 3, type errors
   unchanged, confidently-wrong windows 0.307 → 0.213. 0.15 overshoots (identification
   halves).
9. **Mixed action modes — clamp on private, vary on shared.** *Student: high priority, since
   the theory already says this is what effective coordination needs.* Justification in
   `BIBLIOGRAPHY.md` §19: identifiability depends on intervention TARGETS not values
   (`hauser2012interventional`), so clamp and vary are equally powerful in the limit; the
   difference is finite-sample and role-dependent. Vary keeps variance in your own target so
   the correlation channel works; clamp removes a hidden common cause's variance so the
   confounded association VANISHES for partners. Currently `--vary_only` everywhere.

## Tier 3 — student has moved these from "further work" to "attempt tonight"

10. **k-agnostic policy.** The GNN is instantiated per window size (the role buffer is size
    k), so a trained policy is locked to one k. Sharing weights across k is an engineering
    change and a prerequisite for "pretrain on diverse topologies".
11. **Private sets ≥ 2 per agent.** Required for two independent reasons: the disclosure
    privacy claim is empty at one private node each (agent identity ≡ node identity), and
    windows of k = 5–6 are needed for the diversity story. Note the cost ceiling: version
    space enumeration is 3^(edges in window), so k ≤ 6 is the usable range and dense k=7
    windows rejected 94% of sampled worlds.

## Further work — name in the dissertation, do not build this week

- **JCI regime indicator**: context variables as nodes, CONDITION rather than exclude or
  stratify. Note that stratifying halves the usable rows while conditioning costs one degree
  of freedom — the JCI formulation is the cheap one, and my earlier "stratify" proposal was
  wrong. Adaptivity caveat in `BIBLIOGRAPHY.md` §19.
- **Clique attribution**: recovering which agent's private variables influence which of your
  visible ones — formally the neighbours of the context node under JCI.
- **Domain randomisation over BELIEF SHARPNESS**, then re-test transfer with the control
  that decides it: pretrained-then-finetuned vs randomly-initialised-then-finetuned for the
  same number of noisy episodes. Without that control any benefit could be architecture
  rather than pretraining.

## The thesis framing this supports

Not "we pretrain cheaply and it transfers" — the data contradicts that. Rather: coordination
policies for experiment selection can be learned in a combinatorial idealisation at ~1000x
lower cost per episode; naive transfer fails; the gap is between BELIEF DISTRIBUTIONS, not
causal mechanisms; and randomising belief sharpness either closes it or localises the
bottleneck in the inference engine rather than the policy. That framing survives either
outcome.

## CORRECTION carried into this agenda

I twice stated that Markov equivalence leaves shared-block directions "unorientable no
matter what you do". **That is wrong.** Markov equivalence constrains OBSERVATION. The
reveal channel is pairwise ancestry, and for an adjacent pair u→v iff u is an ancestor of v,
v→u iff the reverse, u↔v iff neither — so intervening on BOTH endpoints fixes the mark with
no residual ambiguity. Intervene on every node and the window is fully determined. The
exemption in `cb/claims.py` is therefore a GRADING CHOICE, not a necessity, and item 6
removes it.
