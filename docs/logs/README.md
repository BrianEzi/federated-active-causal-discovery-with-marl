# docs/logs/ — the primary record, preserved verbatim

These are chronological and are **not** edited to reflect what we later learned. Their value
is precisely that they were written as things happened, wrong turns included, with
`[MEASURED]` / `[DECIDED]` / `[CORRECTED]` entries in the order they occurred.

**READ THIS BEFORE CITING ANYTHING FROM HERE.** Because they run forwards, a claim can appear
confidently and be withdrawn two hundred lines later. Several have been. Examples that have
already misled a reader once:

- oracle-agreement figures of 99.4-100% -- the metric was 93-98% vacuous
- "the greedy oracle never clamps" -- greedy is INDIFFERENT between clamp and vary
- every two-agent number measured before 2026-08-21 -- superseded protocol

`docs/STATE_OF_TRUTH.md` is the supersession layer. It exists specifically so that a claim
retracted here cannot be resurrected by someone reading forwards. Check a claim there before
using it.
